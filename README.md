# RTL Markdown Studio

עורך Markdown סטטי עם תצוגה מקדימה המותאמת למסמכים המשלבים עברית, English וקוד. אין צורך בחשבון, בספריות חיצוניות או בשרת שמקבל את תוכן המסמך.

## הפעלה

משרת HTTP סטטי בתיקיית המאגר:

    python3 -m http.server 8000

פותחים http://localhost:8000. אפשר גם לפרוס את הקבצים ב־GitHub Pages. מומלץ לשרת באמצעות HTTP או HTTPS בגלל טעינת ES Modules.

## יכולות

- עורך Markdown וצידו תצוגה מקדימה בזמן אמת.
- **מבנה מסמך חי:** רשימת כותרות Markdown (H1–H6) לפי סדר הופעתן, עם מספרי שורות ולחיצה להעברת סמן העריכה למקור. כותרות בתוך בלוקי קוד מגודרים אינן נספרות.
- בחירת כיווניות: **זיהוי אוטומטי לכל בלוק**, ימין לשמאל או שמאל לימין.
- עיצוב כותרות, פסקאות, רשימות ממוספרות ולא ממוספרות, ציטוטים, הדגשה, קישורים, קטעי קוד וקווים מפרידים.
- כיווניות LTR מבודדת לקטעי קוד כדי שסימנים ופיסוק לא יזוזו בתוך טקסט עברי.
- שמירת טיוטה אוטומטית באמצעות localStorage — במחשב ובפרופיל הדפדפן הנוכחיים בלבד.
- ייבוא קובצי Markdown, ייצוא קובצי Markdown ו־HTML, העתקת HTML והדפסה/שמירה ל־PDF.
- Ctrl/Cmd+S להורדת Markdown; Tab בעורך מוסיף הזחה; תצוגה עם אפשרות להגדלת גופן.

## אבטחה ופרטיות

ה־Markdown נבנה לרכיבי DOM באמצעות \`document.createElement\` ו־\`textContent\`, ולא באמצעות פירוש תגיות HTML מתוך המסמך. קישורים נפתחים רק לפרוטוקולים HTTP, HTTPS או mailto, עם \`noopener noreferrer\`. HTML שהוקלד כמקור מוצג כטקסט מילולי; הוא אינו מתפרש כקוד HTML או JavaScript.

תוכן המסמך לא נשלח לשרת. הטיוטה נשמרת מקומית בדפדפן; ייצוא קבצים נשלט על ידי המשתמש. פתיחת קישור חיצוני עשויה ליצור בקשת רשת ליעד הקישור.

## תחביר נתמך ומגבלות

המערכת תומכת במתכוון ב**תת־קבוצה של Markdown**, ולא מממשת את כל CommonMark: כותרות \`#\`–\`######\`, רשימות פשוטות, ציטוטים, פסקאות, הדגשה רגילה, קוד בין backticks, בלוק קוד מגודר, קישורים וקווים אופקיים.

בגרסה זו אין טבלאות Markdown, תמונות, רשימות מקוננות או HTML גולמי. שילובי סימון מורכבים וקינון הדגשות אינם נתמכים במלואם. מגבלת המקור היא 200,000 תווים; מגבלת ייבוא קבצים היא 200KB. רכיב הניווט מציג עד 250 כותרות (אם יש יותר, הוא מודיע שהמבנה אינו זמין, אך התצוגה המקדימה ממשיכה לפעול).

**סטטוס:** קוד הפיתוח הועלה אך לא הורצו בדיקות, בהתאם לבקשה לבצע את סבב הבדיקות במרוכז לפני מיזוג.

## מבנה

- \`styles.css\` — עיצוב רספונסיבי והדפסה.
